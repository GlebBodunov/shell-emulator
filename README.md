# Эмулятор командной оболочки UNIX

Учебный проект по дисциплине «Конфигурационное управление», вариант 3.
Язык реализации — Go.

## Требования

- Go 1.21 или новее
- bash (macOS/Linux — Терминал, Windows — Git Bash)

## Структура проекта

| Путь | Назначение |
|------|------------|
| `src/main.go` | Точка входа программы |
| `src/shell/` | Пакет с логикой эмулятора |
| `tests/` | Автоматические тесты |
| `startup/` | Стартовые скрипты для эмулятора |
| `scripts/` | Скрипты ОС для проверки эмулятора |
| `run.sh` | Скрипт запуска |

## Сборка и запуск

## Сборка и запуск

```bash
./run.sh                                  # запуск эмулятора
./run.sh -vfs vfs/deep -script startup/stage2.txt   # запуск с параметрами
go build -o emulator ./src                # сборка исполняемого файла (не коммитится)
go test ./tests/...                       # запуск тестов
```

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `-vfs <путь>` | Путь к физическому расположению VFS (директории на диске) |
| `-script <путь>` | Путь к стартовому скрипту |
| `-h` | Справка по параметрам |

При запуске эмулятор выводит отладочную информацию обо всех параметрах.

## Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку.

- Строки, начинающиеся с `//`, — комментарии (синтаксис Go), они пропускаются.
- Пустые строки пропускаются.
- Перед каждой командой печатается приглашение и сама команда,
  поэтому вывод выглядит как диалог с пользователем.
- Ошибка в строке выводится на экран, выполнение продолжается.
- Если скрипт не завершился командой `exit`, после него запускается
  интерактивный режим.

## Скрипты для проверки

Запускаются из корня проекта:

| Скрипт | Что проверяет |
|--------|---------------|
| `scripts/params_none.sh` | Запуск без параметров |
| `scripts/params_vfs.sh` | Только параметр `-vfs` |
| `scripts/params_script.sh` | Только параметр `-script` |
| `scripts/params_all.sh` | Оба параметра |
| `scripts/params_bad.sh` | Несуществующий стартовый скрипт (ошибка) |

## Функции

- **Приглашение к вводу** формируется из реальных данных ОС: `username@hostname:~$`.
- **Парсер** разбивает строку по пробелам и раскрывает переменные окружения
  реальной ОС: `$HOME`, `${USER}` и т.п.
- **Обработка ошибок**: при вводе неизвестной команды выводится
  `<имя>: команда не найдена`, работа продолжается.

### Команды

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | Заглушка: выводит своё имя и аргументы |
| `cd [аргументы]` | Заглушка: выводит своё имя и аргументы |
| `exit` | Завершает работу эмулятора |

## Пример использования

```
gleb@MacBook:~$ ls -l $HOME
ls -l /Users/gleb
gleb@MacBook:~$ foo
foo: команда не найдена
gleb@MacBook:~$ exit
```

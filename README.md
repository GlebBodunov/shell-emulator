# Эмулятор командной оболочки UNIX

Учебный проект по дисциплине «Конфигурационное управление», вариант 3.
Язык реализации — Go.

Эмулятор имитирует работу командной строки UNIX-подобной ОС:
печатает приглашение, разбирает введённые команды и выполняет их.
Работа ведётся с виртуальной файловой системой (VFS), которая
загружается с диска в память.

## Требования

- Go 1.21 или новее
- bash (macOS/Linux — Терминал, Windows — Git Bash)

## Структура проекта

| `tests/` | Автоматические тесты |

| `vfs/` | Примеры VFS |
| `run.sh` | Скрипт запуска |

## Сборка, запуск и тесты

Все команды выполняются из корня проекта.

```bash
./run.sh                                          # запуск эмулятора
./run.sh -vfs vfs/deep -script startup/stage3.txt # запуск с параметрами
go build -o emulator ./src                        # сборка исполняемого файла
go test ./tests/...                               # запуск тестов
go test -v ./tests/...                            # тесты с подробным выводом
```

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `-vfs <путь>` | Путь к директории на диске, из которой загружается VFS |
| `-script <путь>` | Путь к стартовому скрипту |
| `-h` | Справка по параметрам |

При запуске эмулятор выводит отладочную информацию обо всех параметрах.
Если VFS не удалось загрузить, выводится ошибка и эмулятор завершается
с кодом 1.

## Функции

- **Приглашение к вводу** формируется из реальных данных ОС:
  `username@hostname:~$`.
- **Парсер** разбивает строку по пробелам и раскрывает переменные
  окружения реальной ОС: `$HOME`, `${USER}` и т.п.
- **Обработка ошибок**: при ошибке команды выводится сообщение,
  работа продолжается.

## VFS (виртуальная файловая система)

- Источник VFS — директория на диске пользователя (параметр `-vfs`).
- При запуске директория целиком (со всеми вложенными папками и файлами)
  читается в память. Все операции выполняются только в памяти,
  исходные файлы не изменяются.
- Без параметра `-vfs` используется пустая VFS.
- Команда `vfs-save` сохраняет состояние VFS на диск в исходном формате:
  папки — папками, файлы — файлами.

Примеры VFS в папке `vfs/`:

| Папка | Вариант |
|-------|---------|
| `vfs/minimal` | Минимальная: один файл |
| `vfs/files` | Несколько файлов |
| `vfs/deep` | Файлы и папки с 4 уровнями вложенности |

## Команды

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | Заглушка: выводит своё имя и аргументы |
| `cd [аргументы]` | Заглушка: выводит своё имя и аргументы |
| `vfs-save <путь>` | Сохраняет VFS на диск по указанному пути. Путь не должен существовать |
| `exit` | Завершает работу эмулятора |

## Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку.

- Строки, начинающиеся с `//`, — комментарии (синтаксис Go), они пропускаются.
- Пустые строки пропускаются.
- Перед каждой командой печатается приглашение и сама команда,
  поэтому вывод выглядит как диалог с пользователем.
- Ошибка в строке выводится на экран, выполнение продолжается.
- Если скрипт не завершился командой `exit`, после него запускается
  интерактивный режим.

## Примеры использования

Интерактивный режим:

```
$ ./run.sh -vfs vfs/deep
[debug] параметры запуска:
[debug]   -vfs    = "vfs/deep"
[debug]   -script = ""
[debug] VFS загружена из vfs/deep
gleb@MacBook:~$ ls -l $HOME
ls -l /Users/gleb
gleb@MacBook:~$ vfs-save out/copy
VFS сохранена в out/copy
gleb@MacBook:~$ vfs-save out/copy
vfs-save: out/copy: путь уже существует
gleb@MacBook:~$ foo
foo: команда не найдена
gleb@MacBook:~$ exit
```

Проверка работы с VFS через скрипт:

```
$ ./scripts/vfs_deep.sh
```
